# 其他已知问题

本文件记录两个与启动无关的问题：音频采样率与睡眠唤醒。启动阶段的两个问题见 [boot-issues.md](boot-issues.md)。

## 音频：采样率降低一档时出现尖锐噪声

### 现象

声卡可以正常发声。把输出采样率从当前档位向下一档调整后，播放时出现持续的高频尖锐声音。把采样率调回原档位或向上一档调整后，声音恢复正常。

### 临时方案

在「音频 MIDI 设置」中把输出采样率保持在当前档位，或者向上一档调整。日常播放使用该档位即可正常使用。

### 状态

现象可以稳定复现，具体原因待定位。同型号机器遇到相同表现时，可以先用调整采样率的方式恢复播放。
